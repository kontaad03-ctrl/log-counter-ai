# マルタ・カゾエール

写真から丸太を自動検出し、本数を集計するWebアプリです。

PCとスマートフォンに対応しており、自動検出後にマーカーを手作業で修正できます。

## 主な機能

- 複数写真の読み込み
- ONNXモデルによる丸太の自動検出
- 写真ごとの本数と全写真の合計表示
- マーカーの追加・削除
- PCでのマーカー移動
- 矩形・ポリゴンによる検出除外
- 比較画像の表示
- CSV形式での集計結果保存
- `.omc`形式でのプロジェクト保存・読込
- 案件メモの保存
- ブラウザ内への履歴保存
- PC・スマートフォン対応

自動検出について

「🤖自動検出」を押すと、現在表示している写真を解析します。

自動検出をもう一度実行すると、表示中の写真のマーカーは新しい検出結果に置き換わります。

マーカーが付きすぎる場合

検出信頼度を上げて、もう一度自動検出してください。

同じ丸太に複数のマーカーが付く場合

重なり許容度を下げて、もう一度自動検出してください。

自動検出結果は、必要に応じて目視で確認・修正してください。

除外機能
矩形除外

PC版で使用できます。

「🚫矩形除外」を押し、写真上をドラッグして四角い除外範囲を作成します。

ポリゴン除外

自由な形の除外範囲を作成できます。

PC版では、左クリックで頂点を3点以上追加し、ダブルクリックで確定します。

スマートフォン版では、写真上をタップして頂点を追加し、「✅確定」を押します。

除外範囲の中は、自動検出の対象外になります。

履歴には最新30件まで保存されます。

31件目以降を保存すると、最も古い履歴から自動的に削除されます。

保存場所

履歴はブラウザのIndexedDBへ保存されます。

PCとスマートフォンの履歴は、端末・ブラウザごとに別々に管理されます。

履歴に関する注意

ブラウザの閲覧データやサイトデータを削除すると、履歴も消える場合があります。

履歴を削除しても、端末やPCへ保存済みの .omc ファイルは削除されません。

大事な案件は、履歴だけでなく .omc ファイルも保存してください。

CSV保存

「CSV保存」を押すと、次の内容を保存できます。

写真ごとのファイル名

保存したCSVファイルは、Microsoft Excelなどの表計算ソフトで開くことができます。
